# CometChat Marketing Landing Page

This project is a responsive SaaS-style marketing landing page built using **Svelte** and **Tailwind CSS**.  
It replicates a modern marketing website layout focusing on **clean component architecture, performance, and SEO best practices**.

## Live Demo

https://cometchat-marketing-landing-demo.vercel.app/

- Vite

- JavaScript
- HTML5
- CSS3

## Features

- Responsive marketing landing page
- Component-based architecture
- Semantic HTML structure
- Basic SEO optimization
- Optimized image usage
- Mobile-first design
- Clean and maintainable code structure

## SEO Considerations

- Semantic HTML elements
- Proper heading hierarchy (H1 → H2 → H3)
- Descriptive image alt attributes
- Meta title and meta description
- Mobile-first responsive design

## Installation

Clone the repository:

git clone https://github.com/deenadayalan1810-bot/cometchat-Marketing-landing.git

Install dependencies:

npm install

Run development server:

npm run dev

Build for production:

npm run build

## Deployment

This project is deployed using **Vercel**.
